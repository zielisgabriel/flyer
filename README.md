# 🧾 **Flyer**

### O termo flyer está diretamente associado à rapidez, à ampla distribuição e à ideia de algo que “voa” de mão em mão. Tradicionalmente, trata-se de um material gráfico promocional de página única, sem dobras, criado para comunicar informações de forma objetiva, dinâmica e com alto impacto visual.

### Nossa aplicação leva esse conceito para o ambiente digital. Essa rede social funciona como uma plataforma de flyers digitais, capaz de veicular diferentes tipos de conteúdo, desde GIFs e vídeos curtos e descontraídos até notícias relevantes e informativas do mundo real.

### A entrega do conteúdo é orientada por um algoritmo configurável, no qual o próprio usuário pode definir critérios e prioridades de exibição. Caso prefira, também é possível utilizar o modo automático, permitindo que o sistema gerencie a distribuição de forma inteligente e otimizada.
